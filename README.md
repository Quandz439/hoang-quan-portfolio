# Hoàng Quân Nguyễn — Personal Portfolio

Website cá nhân phong cách navy-gold, xây dựng bằng HTML, CSS và JavaScript thuần, tương thích GitHub Pages.

## Cấu trúc

- `index.html`: nội dung và cấu trúc trang.
- `css/style.css`: giao diện responsive và hiệu ứng.
- `js/script.js`: menu mobile, hiệu ứng xuất hiện khi cuộn, điều hướng đang chọn và nút quay về đầu trang.
- `assets/favicon.svg`: biểu tượng trình duyệt.

## Chạy website

Mở `index.html` trong trình duyệt để xem thử, hoặc triển khai qua GitHub Pages.

## Bật GitHub Pages

1. Vào **Settings → Pages** trong repository.
2. Ở mục **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn branch `main` và thư mục `/(root)), sau đó nhấn **Save**.
4. Đợi GitHub Pages hoàn tất triển khai. URL dự kiến: https://quandz439.github.io/hoang-quan-portfolio/

## Chỉnh sửa nội dung

- Tên, đoạn giới thiệu và các mục nội dung: sửa trong `index.html`.
- Màu sắc: chỉnh các biến CSS ở đầu `css/style.css` (ví dụ `--navy-950`, `--gold`).
- Hành vi tương tác: sửa trong `js/script.js`.
- Muốn thêm liên hệ thật, hãy thêm email hoặc liên kết mạng xã hội của bạn vào phần Contact trong `index.html`. Hiện trang chưa công khai thông tin liên hệ cá nhân.

## Ghi chú

- Không dùng backend hay cơ sở dữ liệu.
- Google Fonts là tài nguyên bên ngoài; nếu không có mạng, trình duyệt sẽ dùng font dự phòng.
- Website không có biểu mẫu gửi dữ liệu hay chức năng liên hệ giả.
- Nội dung dự án hiện là mô tả của chính website; hãy thay bằng dự án thật khi sẵn sàng.
